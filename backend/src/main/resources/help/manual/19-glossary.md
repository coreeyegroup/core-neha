# Glossary
> Terms used in the system and in this manual.
<!-- audience: everyone -->

| Term | Meaning |
|---|---|
| ABHA | Ayushman Bharat Health Account number (14 digits) of the national digital health mission |
| Anterior segment | Front of the eye: lids, conjunctiva, cornea, iris, lens |
| Assignment | An approved grant of a role to a user at a scope; the only thing that gives access |
| Audit trail | The permanent record of who did what |
| BCVA | Best corrected visual acuity |
| CF / HM / PL / NPL | Counting fingers / hand movements / perception of light / no perception of light |
| Centre | A hospital, clinic, store or laboratory of the group |
| Cylinder, axis | Astigmatism correction and its direction (0–180°) |
| Day close | The daily reconciliation of cash and other payments |
| Establishment | A position created at a centre with an approved headcount |
| FTE | Full-time equivalent: 1.00 full time, 0.50 half time |
| ICD-10 | International classification of diseases codes, for example H25.1 |
| IOL | Intraocular lens implanted in cataract surgery |
| IOP | Intraocular pressure, in mmHg |
| Legal entity | The registered company running a centre |
| Node | A place in the organisation hierarchy (state, city, area) |
| Phaco | Phacoemulsification, modern cataract surgery |
| Posting | A person holding an established position, with dates and FTE |
| Price list (tariff) | A centre's chargeable services and packages |
| Responsibility | Recorded accountability that gives no access |
| Role / role version | A named set of permissions / one approved edition of it |
| Scope | Where an assignment applies: a centre, a node and below, or the group |
| SICS | Small incision cataract surgery |
| Snellen (6/6, 6/60) | Distance vision notation |
| Sphere | Short- or long-sightedness correction in dioptres (D) |
| Token | A patient's queue number for the day at a centre |
| TPA | Third-party administrator handling insurance claims |
| UHID | Unique health identifier: the patient's number for the whole group |
| Visit | One attendance at a centre, worked on by every department |
