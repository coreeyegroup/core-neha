# ADR-0002: Version matrix and pinning policy

- Status: Accepted
- Date: 2026-11-04

Exact pins for all images, Maven and npm dependencies, following the policy in `docs/versions/VERSIONS.md` (npm releases at least 14 days old; Spring Initializr default and mappings for the JVM stack; supported/LTS lines only). Upgrades are planned changes recorded in the change log of that file.
